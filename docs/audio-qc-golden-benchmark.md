## 标签与任务必须匹配

已有正式标签可以作为其任务的 gold。需要记录标签来源、版本和限制；gold 不代表绝对无错，也不代表任意领域都适用。

| 资源 | 可用标签 | 可自动回答的问题 | 不能直接回答的问题 |
| --- | --- | --- | --- |
| 本地 LibriSpeech test-clean / test-other | 官方录音级参考转录、说话人和章节 ID | ASR WER；QC 是否优先选中错误较多的录音 | 人工词边界、VAD 帧标签、音质错误 |
| FLEURS en_us / cmn_hans_cn | 官方参考转录 | 英语 WER、中文 CER；跨语言排序价值 | 精确疑点时间定位、真实劳动时间 |
| AVA-Speech（后续可选，未下载） | 稠密 speech/non-speech 及背景条件区间 | VAD 漏检、误报；噪声/音乐条件分层 | 单词转录正确性 |
| 可复现受控变体 | 变换类型、范围、强度与父录音 | 已知低电平、削波、静音或删除转录的检出和定位 | 自然音质问题的总体准确率 |

本地准备记录确认 LibriSpeech 共 5,559 条、38,682.05 秒；参考在 `runtime/datasets/librispeech/official-test/prepared/references.jsonl`。本次检查时 `runtime/librispeech-base-2026-10-17/run.json` 仍记录 `running`，尚无完成的全量合并 ASR/评分文件；不重复启动或干预该任务。已有 20 条中英文 FLEURS 可验证代码，但属于训练分割前缀冒烟集，不能当最终泛化测试。

官方来源：[LibriSpeech](https://www.openslr.org/12/)、[FLEURS](https://huggingface.co/datasets/google/fleurs)、[AVA-Speech 标签说明](https://sites.research.google/gr/ava/download/)。公开转录语料和 VAD 语料的标签不可混用。现有 Whisper 词时间戳属于模型预测；forced alignment 生成的边界也应标记为自动对齐，不能当作独立人工时间 gold。例如 [AMI 官方说明](https://groups.inf.ed.ac.uk/ami/corpus/transcription.shtml)明确区分人工转录与自动强制对齐产生的词/音素时间。

## 第一轮：冻结 v1，评估错误筛选价值

复用现有 ASR 完整结果和 `scripts/evaluate_speech_smoke.py`，保持其规范化、失败分母、哈希及参考隔离规则：

1. 在接触测试标签前冻结排序规则、消融条件、预算点和统计方案。当前规则尚未定义出经校准的错误概率，不应直接把 issue 数当成概率。
2. 检测器只读取音频、ASR 文本和预测时间戳，输出原始指标、疑点及排序分数。参考文本不进入推理、LLM prompt 或排序特征。
3. 离线评分器连接官方参考，得到逐录音替换/删除/插入计数和整体 WER/CER。文本对齐可以产生文字错误位置，但不保证错误的声学时间边界。
4. 比较预先定义的 DSP、DSP+VAD、DSP+VAD+覆盖信号，以及随机排序和时长排序基线。消融针对排序输入；不能把共享中间计算的耗时称为独立模型耗时。
5. 按待复核音频时长预算 5%、10%、20%、30% 报告：选中录音所包含的错误词/字符比例、错误录音比例、未选中部分残留 WER/CER。给出完整风险—覆盖曲线，不能只选择最好的一点。随机基线使用固定多组种子。
6. 按官方 split、说话人、时长及语言分层；按说话人或父录音做分组 bootstrap 置信区间。失败、缺失、无疑点和无法评分的条目保留完整分母与原因。

例如，“选取 20% 的音频时长覆盖了多少参考文本错误”是可自动计算的筛选指标。它只表示这些录音包含多少错误，不能假定审核者必然找到并修正全部错误，更不能直接宣称节省 80% 人工时间。实际循环回听和界面操作收益仍需单独的人机实验。

注意区分机制效果与下游用途：低电平提示即使发生在 WER=0 的录音，也不一定是 DSP 误报。用 WER 评价的是其筛选 ASR 错误的价值；验证“是否低电平”要使用对应声学标签。

## 第二轮：独立标签与受控异常

VAD 帧级实验使用有 speech/non-speech 区间的独立标签，预先固定帧宽、边界容差、重叠语音及非语言发声约定。报告 precision、recall、F1、漏检/误报时长，并按背景条件分层；获取和解码失败保留记录。

DSP 与覆盖实验对父录音生成多强度、不同位置的受控变体：减小电平、已知幅度削波、加入静音、删除部分带时间戳的转录、保留文字却替换对应音频等。保留未变换对照，分别统计检出率、非目标区间提示负担和可定义区间的定位误差。合成标签仅证明对已知变换的响应，不能替代自然异常标签。所有变体随父录音进入同一数据分割。

当前 ASR 的 `vad_filter=True` 与 QC 都使用 faster-whisper 中的 Silero VAD，可能共享漏检。增加关闭 ASR VAD 的配对对照，或不同 VAD 家族的辅助信号，评估新增错误、计算成本及共同漏检。无 VAD 对照还可能增加幻觉/耗时，结果应完整保留；两模型一致不是 gold。

## 第三轮：用 gold 自动训练和选型

为学习排序、阈值选择和校准准备独立开发数据。现有 LibriSpeech test-clean/test-other 保留为固定 v1 测试；不能在其标签上调好规则，再把该结果当成无偏最终测试。若根据已查看测试结果进行持续迭代，需要新的留出集。模型预训练是否见过公开语料通常不能确认，应记录这一限制。

可从可解释的逻辑回归或小型树模型开始，以 DSP 指标、覆盖率、ASR 置信特征和多模型分歧预测录音是否有较高错误风险。训练目标由开发集参考自动生成，分类阈值和分数校准只在开发数据上选择；测试推理看不到参考。先证明学习排序优于冻结规则及简单基线，再增加复杂模型。

第二路 ASR 或 LLM 输出只作为候选。自动评估纠错前后 WER/CER、纠正错误的数量、将正确文字改错的数量，以及延迟和成本；保存原始候选和退化案例。不能让同一 LLM 生成候选并以自己的判断充当独立 gold。

## 记录与产品功能

建议新增独立 `golden-benchmark` 评测入口，复用现有评分器并输出：冻结协议、数据与源码哈希、配置/种子、逐条预测与参考评分、分组结果、风险—覆盖曲线、消融比较、失败记录和运行成本。真实 gold、自动对齐、受控合成标签、模型伪标签分别标明来源。

Anota 可据此增加“按风险排序、按复核预算筛选、自动回归报告”功能。人工参与可以集中于标签缺失的新领域、模型无法校准的高分歧案例和必要抽检；已有标注任务上的离线迭代无需等待新的人工审核。
